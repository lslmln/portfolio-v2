Portfolio v2 — an in-progress overview/highlight-reel rebuild of [`lslmln/portfolio`](https://github.com/lslmln/portfolio) (v1). v1 stays live for applications; this is the "take more time on it" version.

See `CLAUDE.md` for project rules and `docs/v1-retrospective.md` for what's carried over from v1, what's being left behind, and how sections should be built this time. Visual design direction is intentionally not yet decided.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
